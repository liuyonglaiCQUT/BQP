# External model sources

- `CompoundE/` and `ULTRA/` are pinned MIT-licensed source snapshots. Their
  data, pretrained weights, `.git` directories, and generated files are not
  included.
- `SimKGC/` is created by `../scripts/setup_third_party.sh` from the official
  pinned upstream commit. It is deliberately not vendored because that commit
  does not provide a license file.

See `../../THIRD_PARTY.md` for provenance and modification details.
