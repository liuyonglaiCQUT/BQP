# BQP 多架构与算法级扩展协议

冻结日期：2026-10-18。本协议针对 FB15k-237 和 WN18RR 的正式测试排名冻结。新增 NELL-995 只扩展 ComplEx/DistMult 核心分析与覆盖率实验，不进入本多架构矩阵。固定测试集 MRR 是精确的描述值；此处的源三元组推断针对各测试 split 的条件重采样目标，不外推到其他图或训练随机性。

## 研究问题

1. 在相同训练种子下比较不同架构时，查询独立推断与源三元组簇推断是否会改变显著性判断？
2. 将五个训练种子汇总为算法均值并同时考虑训练随机性与测试三元组不确定性后，BQP 是否仍会改变判断？

## 实验矩阵

- 数据集：FB15k-237、WN18RR；
- 已有架构：ComplEx、DistMult；
- 新增架构：CP、RotatE；
- 种子：7、11、19、23、31；
- checkpoint 只依据 `all_known` filtered validation MRR 选择；测试集不参与调参或选择；
- 测试排名继续使用 `train+valid+test` filtered ranking 与 average-rank 并列规则。

新增架构先用种子7进行开发集调参。每个“数据集×架构”只选择一套配置，随后原样运行其余四个种子。
调参候选、验证集结果与最终选择必须写入训练清单。模型采用 reciprocal-query 训练；CP 使用独立主语/宾语
实体因子，RotatE 使用复平面旋转及平方 L2 排序。二者均采用负采样 logistic loss，以便在单张8GB GPU
上完成；训练方法差异属于算法实现的一部分，所有模型仍共享完全相同的正式测试评估器。

## Checkpoint 级同种子比较

每个数据集、每个种子枚举四个架构的全部无序模型对，共
`2 × 5 × C(4,2) = 60` 项。模型差值保留同一查询与同一源三元组的配对：

- 查询独立法分别重采样头、尾方向的差值；
- BQP 修正法共同重采样同一源三元组的头、尾差值；
- 初筛采用解析标准误、双侧正态 p 值和10,000次 Gaussian multiplier bootstrap。乘子在所有架构间共享，
  查询独立版本对头、尾使用独立乘子，源三元组版本对同一事实的两个方向使用共同乘子；
- 任一方法在 `p<0.05` 或95% CI跨零判断上产生差异，即为候选；候选用200,000次乘子bootstrap确认；
- 每个数据集的30项同种子比较另行执行Benjamini–Hochberg校正。

“同种子”仅使随机数标签匹配，并不能保证两个架构经历相同优化轨迹；它比跨种子checkpoint比较更干净，
但仍然是单次训练实例的比较。

## 算法级比较

每个数据集枚举 `C(4,2)=6` 个架构对，共12项。算法效应定义为五个匹配种子上测试MRR差值的均值。
主推断采用两种互补方法：

1. **seed-only 配对 t 推断**：以五个种子差值为五个独立训练重复，只回答训练随机性下的算法差异；
2. **seed × source-triple 两维乘子bootstrap**：使用两维加性影响函数，对训练种子和源三元组分别施加
   均值为0、方差为1的高斯乘子。正确版本以源三元组内头尾均值为单元；查询独立版本对头、尾方向使用
   独立的三元组乘子，但共享训练种子乘子。两种版本均保留跨架构配对。解析两维簇方差另外包含有限
   `seed×triple` 单元的交集扣除项，作为乘子近似的核验。

两维推断使用50,000次初筛；出现显著性差异的候选增加到200,000次确认。由于只有五个训练种子，
算法级结果必须同时报告效应量、五个种子差值、seed-only区间以及两维区间，不仅报告一个p值。

## 预定结论边界

- 至少一个200,000次确认的同种子翻转，只能证明BQP能改变更干净的真实checkpoint比较；
- 算法级两维推断翻转且seed-only结果位于决策边界，才可声称BQP会影响当前矩阵中的算法级判断；
- 没有算法级翻转时，仍报告区间膨胀程度，不把checkpoint级翻转升级为算法优劣翻转；
- 不根据测试集结果修改模型超参数、排除种子或增加特定模型对。

NELL-995 的核心分析目标另见 `docs/core_analysis_protocol.md` 和 `docs/nell995_data_protocol.md`；其结果不增加
本四架构比较的运行数，也不支持未实验架构在 NELL 上的结论。
