# BQP 置信区间覆盖率实验协议

冻结日期：2026-10-18。本协议在生成覆盖率结果前确定。

## 目的

既有实验已经证明查询独立法会系统性低估标准误，但“区间更窄”不直接等于“区间失准”。本实验直接
测量名义95%置信区间的实际覆盖率：在重复抽样中，一个方法声称的95%区间有多少次真正包含目标MRR。

## 目标总体与抽样单位

每个 benchmark 的完整 test split 首先是一个有限总体；对这份已经完整评估的测试集，MRR 是精确的
描述性统计量，本身没有测试事实抽样误差。本实验不把 bootstrap 区间解释成这项已知 MRR 的不确定性。

本实验另外定义一个条件重采样目标：把该 split 的源三元组视为某个 benchmark 特定事实分布的经验近似，
以源三元组为单位反复抽取大小为 `n` 的样本，检验两种标准误对该经验总体 MRR 的覆盖表现。每次抽到
一个源三元组 ID 时，同时取出其头、尾 RR。该分析条件于固定数据图、split 和 checkpoint；它不涵盖
图之间的变化、split 构造的不确定性、训练随机种子、未来事实，也不保证现实知识图谱满足 IID 或可交换
抽样假设。

NELL-995 使用本地完整图生成的随机关系分层 split，而非声称复现标准 benchmark 的事实分配。其有限
经验目标总体为该 split 的 3,992 个测试三元组，200 种关系均有测试事实。详见
[`nell995_data_protocol.md`](nell995_data_protocol.md)。FB15k-237 和 WN18RR 的目标总体同样限定为
各自固定测试 split 的经验分布。

所有方法使用相同样本、相同点估计和同一个正态临界值1.959964，仅标准误计算不同：

- 查询独立：`sqrt[(s_tail^2 + s_head^2) / (4n)]`；
- 源三元组簇：先计算每个事实的 `(RR_tail + RR_head)/2`，再用其样本标准差除以 `sqrt(n)`。

不使用有限总体修正，因为抽样是有放回的。覆盖事件定义为完整经验总体MRR落入
`estimate ± 1.959964 × SE`。

## 正式矩阵

1. **单模型覆盖率曲线**：FB15k-237 与 WN18RR 各含4个架构，NELL-995 含核心 ComplEx/DistMult；
   共200个“运行×样本量”设置（`n ∈ {250, 500, 1000, 2000}`），每项3,000次重复；
2. **模型差值覆盖率**：FB15k-237 与 WN18RR 各枚举4架构的6个无序对，NELL-995 比较 ComplEx−DistMult；
   五个种子共65项，样本量固定为1,000，每项3,000次重复；模型保持查询级和源三元组级配对；
3. **去配对空对照**：对各数据集实际纳入的单模型运行，以确定性随机置换将 head RR 重新分配给其他源三元组，
   保持 tail/head 边际分布不变但破坏同源配对；共100个“运行×条件”设置，样本量1,000，每项3,000次重复。

同一“数据集×样本量×分析族”内的模型共享抽样ID，使不同模型的蒙特卡洛误差可比较。所有覆盖率
使用二项分布Wilson 95%区间报告。3,000次重复下，95%附近的蒙特卡洛标准误约0.4个百分点。

## 预定汇总与判据

- 分别报告每个数据集和架构的平均覆盖率，以及运行间最小—最大值；
- 报告查询独立覆盖率相对95%的缺口，以及簇方法覆盖率相对95%的缺口；
- 模型差值结果按数据集和架构对汇总；
- 空对照若使两种方法的覆盖差明显缩小，作为“同源配对导致误校准”的机制证据；
- 不以是否出现单个p值翻转作为本实验成功条件。

## 解释边界

这是针对各自固定测试集经验分布的条件校准实验，描述在“源事实为抽样单位”的明确重采样机制下两种
区间的覆盖行为。若研究者只关心完整固定测试集的已观测 MRR，不需要把这个区间当作该值的误差条；若
研究者要对来自同一 benchmark 特定事实分布的重复样本或近似新样本作推断，则该校准结果才直接相关。
它不证明测试三元组来自现实世界 IID 分布，也不消除共享实体、关系或图社区造成的更高层依赖。因此源
三元组簇区间应解释为修复 BQP 的最小方案，而不是知识图谱所有依赖结构下的最终区间。
