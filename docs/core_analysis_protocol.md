# BQP 核心实验分析协议

本协议在正式测试排名生成后、正式统计分析前固定。分析输入为
`results_bqp/test_query_ranks/` 中 ComplEx 与 DistMult 在三个数据集、五个 seed 上的 30 个通过完整性审计的运行。

## 目标总体

对每个固定测试 split，完整测试 MRR 是精确的描述性统计量。本文的置信区间与覆盖率实验不把它解释为
该已知均值的测量误差；它们针对的是以该 split 的源三元组经验分布为近似、重复抽样源事实时的条件
重采样行为。推断条件于固定图、split 与 checkpoint，不外推到其他图、另一套数据划分或训练随机性。
NELL995 使用项目生成的实体覆盖、关系分层 split，3,992 个 test triples 覆盖全部200种关系，
543 个 validation triples 覆盖196种关系；这不是标准 NELL-995 benchmark 的原始事实分配。详见
`nell995_data_protocol.md`。

## 主要问题

对每个测试三元组 `i`，记尾预测与头预测的 reciprocal rank 为 `T_i`、`H_i`。
标准 KGC MRR 为 `mean((T_i + H_i) / 2)`。

核心问题是：把 `2N` 个方向查询视为相互独立，是否会错误估计该 MRR 的不确定性？

主要效应量为：

`SE ratio = SE_triple-cluster / SE_direction-independent`

其中：

- `SE_direction-independent² = [Var(T) + Var(H)] / (4N)`，忽略同源头尾查询的协方差；
- `SE_triple-cluster² = Var((T + H)/2) / N`，保留每个源三元组内的头尾配对。

同时报告 `design effect = SE ratio²`、等效方向查询样本量
`N_eff = 2N / design effect`，以及实际论文中也可能出现的 pooled-query IID 标准误。

## 正式分析

1. **单模型 MRR**：对数据集 × 模型 × seed 的 30 个运行，计算头尾相关性、解析标准误和
   查询独立/三元组簇 bootstrap 95% 区间。
2. **模型比较**：在相同数据集和 seed 内计算 ComplEx−DistMult 的逐查询 reciprocal-rank 差，
   重复上述分析，检验忽略同源方向依赖是否会缩窄模型差值区间或改变显著性判断。
3. **关系组成控制**：在每个关系内部随机重配 `H_i`，保持关系频数与两个方向的边际分布，生成
   头尾相关性的零分布。它检验真实同源配对的相关性是否高于仅由关系组成造成的相关性。
4. **关系中心化诊断**：分别在每个关系内中心化头、尾 reciprocal rank 后重新计算相关性，作为
   随机重配控制的无随机数补充。

## 固定设置

- bootstrap：50,000 次，percentile 95% CI；
- 关系内随机重配：5,000 次，单侧检验真实相关性是否更大；
- 多重检验：单模型 30 项和模型比较 15 项分别执行 Benjamini–Hochberg 校正；
- 随机数主种子：20261018，并由数据集、模型和训练 seed 派生独立子种子；
- 所有主统计量使用 `float64`；
- 主比较为保持方向规模的 query-independent 与 source-triple cluster；pooled-query IID 仅作附加诊断。

每个训练 seed 单独构成一次测试集不确定性分析。跨 seed 汇总只报告均值和范围，不把五个 seed
当作五条额外测试查询，也不混淆测试集采样不确定性与训练随机性。

### 执行前修订记录

最初拟使用 5,000 次 bootstrap。首次两数据集正式执行在写出任何正式结果前，被预设的“解析与
bootstrap SE 比率差不得超过 0.03”审计拦截：WN18RR/ComplEx/seed 19 的差为 0.038。50,000 次
诊断重采样显示该差异来自有限重采样的蒙特卡洛误差，而非估计公式或配对实现错误，随后两数据集阶段
曾将正式重复数提高到 10,000。

加入预先固定的 NELL995 扩展矩阵后，首次30运行执行同样在写出正式汇总前被该门槛拦截：
NELL995/ComplEx/seed 19 的解析与10,000次 bootstrap SE 比率分别为1.05393和1.08432，绝对差
0.03039。为避免只对失败样本放宽门槛或选择性增加精度，最终30个单模型运行和15个模型差值统一使用
50,000次 bootstrap。关系内置换次数及其他定义不变。

## 判定边界

- `SE ratio > 1` 表示查询独立法低估标准误；小于 1 表示高估标准误；
- bootstrap 与解析结果必须方向一致，解析和 bootstrap SE ratio 的绝对差超过 0.03 时触发审计失败；
- 关系重配的 BH 校正 `q < 0.05` 说明同源配对依赖不能仅用关系组成解释；
- 模型比较同时报告两种 CI 是否跨零，不以是否出现“显著性翻转”作为现象成立的必要条件。
