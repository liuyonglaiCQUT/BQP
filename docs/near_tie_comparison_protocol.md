# BQP 近性能模型全集比较协议

冻结日期：2026-10-18。本文档在生成全集比较结果前确定。

## 目的

核心实验只比较相同随机种子的 ComplEx 与 DistMult，共 10 项，未观察到查询独立区间与
源三元组簇区间之间的显著性判断翻转。本实验扩大真实 checkpoint 比较范围，回答：当两个模型的
测试 MRR 接近时，忽略同源头尾依赖是否会实际改变“差值是否显著”的判断。

## 比较全集

不根据测试差值挑选模型对。对每个数据集，把已冻结的 5 个 ComplEx checkpoint 与 5 个 DistMult
checkpoint 组成 10 个真实训练模型，并枚举全部无序二元组：

- 同模型、不同种子：`2 × C(5,2) = 20` 项；
- 跨模型、相同种子：5 项；
- 跨模型、不同种子：20 项；
- 每数据集共 `C(10,2) = 45` 项，两个数据集共 90 项。

同模型比较按较小 seed 减较大 seed 定向；跨模型比较统一按 ComplEx 减 DistMult 定向。定向只影响
差值符号，不影响区间是否跨零。

“近性能”预先定义为绝对测试 MRR 差不超过 0.005。全集 90 项为主要分母，近性能子集用于回答
BQP 在论文常见微小提升区间中的实际影响。

## 统计量与主判据

对每个模型对和每个源三元组，分别计算尾方向与头方向的 reciprocal-rank 差：

`D_T = RR_T(A) - RR_T(B)`，`D_H = RR_H(A) - RR_H(B)`。

同时计算：

1. 保持方向规模、但分别重采样 `D_T` 与 `D_H` 的 query-independent bootstrap；
2. 共同重采样 `(D_T, D_H)` 的 source-triple cluster bootstrap；
3. 两种方法的解析标准误、正态 95% CI 和双侧 p 值；
4. `SE_cluster / SE_independent`、方向差值相关性和有效样本比例。

每项初筛使用 10,000 次 bootstrap percentile 95% CI。若两种区间对是否跨零给出不同判断，则标记为
bootstrap flip candidate。所有候选使用新的确定性随机种子执行 50,000 次确认 bootstrap；确认阶段仍然
出现判断差异时记为 confirmed bootstrap flip。解析正态区间是否同样翻转作为独立证据。

主报告同时给出：

- 90 项全集中的候选与确认翻转数；
- 近性能子集中的候选与确认翻转数；
- 三类比较各自的翻转数；
- 每个数据集内，基于解析双侧 p 值进行 Benjamini–Hochberg 校正前后的判断变化。

未经多重校正的单项区间对应预先指定一个模型对时的常规论文声明；全集 BH 结果回答在本次穷举分析中
控制 FDR 后结论是否仍改变。二者用途不同，均予报告。

## 边界

- 同模型不同种子的比较可以揭示真实训练实例之间的近性能差异，但不能直接解释为两个算法的优劣；
- 跨模型不同种子的比较混合了架构与训练随机性，单独分层报告；
- 穷举已有 checkpoint 能测量当前模型池中的翻转发生率，不能代表所有 KGC 论文；
- 若未发现翻转，仍报告区间宽度和 SE Ratio，不继续事后修改近性能阈值；
- 若发现翻转，只把 50,000 次确认仍成立的案例写入论文主结果。

## 执行后数值稳健性补充

首次 10,000 次正式运行完成后，percentile CI 没有产生翻转，但发现一项比较同时满足：解析正态区间
发生翻转，且三元组簇 percentile CI 的下界距零仅 `3.83e-6`。这表明“区间是否包含零”可能受到
bootstrap 分位数蒙特卡洛误差和轻微偏度影响。

为审计该边界，而不修改既有 percentile CI 主判据，补充以下次级分析：

1. 以每个模型对的观测差值为中心化基准，从 bootstrap 误差分布计算双侧 p 值：
   `p = [1 + #{|delta* - delta_hat| >= |delta_hat|}] / (B + 1)`；
2. 对查询独立和源三元组簇 p 值分别在每个数据集 45 项比较内执行 BH 校正；
3. 对 percentile CI 翻转、解析正态翻转或中心化 bootstrap p<0.05 判断翻转的并集执行高重复数确认；
4. 本次确认将重复数从原定 50,000 提高到 200,000，以稳定接近零的尾部分位数与 p 值。

该补充是在看到初次边界结果后增加的数值审计，论文中必须标记为 post-hoc robustness check，不能
伪装成预注册主分析。原始 10,000 次 percentile CI 结果保持不变并同时报告。
